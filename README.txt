A LITTLE BIRTHDAY STORY — 19TH BIRTHDAY
=====================================

OPEN / TEST
1. Extract the ZIP and open the birthday-surprise folder in VS Code.
2. Use Live Server to open index.html (or open index.html directly).
3. Add ?test=10 to the local URL for a 10-second countdown.
   Example: http://127.0.0.1:5500/index.html?test=10
4. Add ?preview=1 to skip the countdown locally.
5. On the normal URL the countdown ends at 27 Nov 2026, midnight IST.
   No production date changes are needed. Test parameters are ignored on public hosting.

PERSONALIZE
Open script.js and edit CONFIG.name, CONFIG.from, CONFIG.wish and CONFIG.letter.
The names are intentionally blank, not guesses. The letter is a temporary draft.
The three enhanced portraits are in assets/images/ as optimized WebP images.
No music, external fonts, packages or server required.

GITHUB PAGES
Upload the CONTENTS of birthday-surprise (index.html, style.css, script.js, assets)
into the root of your GitHub repository. Under Settings > Pages, choose Deploy
from a branch > main > / (root), then Save. Open the URL GitHub provides.

PRIVACY
Only publish portraits if the person has agreed to public hosting. GitHub Pages
is public and the countdown is not a security mechanism; the images can be
accessed by URL. The noindex tag is not access control. You may remove the
portraits and use your own graphics if permission has not been obtained.
